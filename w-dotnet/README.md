# UserApi

A modern Minimal API built with .NET 10.

## Features
- **.NET 10.0.300** architecture via `global.json`
- Streamlined **`.slnx` solution** format
- **Central Package Management (CPM)** via `Directory.Packages.props`
- Global build configurations via `Directory.Build.props`

## How to Run
```bash
dotnet restore
dotnet run --project UserApi/UserApi.csproj
